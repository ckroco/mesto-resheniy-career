Браузерная игра «Места решений» для взрослых, которые уже работают и думают, что изменить дальше: задачи, график, окружение или саму профессию.

## Как это работает

1. Опиши, как работаешь сейчас, и выбери, чем хотелось бы заниматься дальше.
2. Укажи, какой доход тебе нужен и готова ли ты временно получать меньше. Поля с суммами можно пропустить.
3. Выбери, что для тебя важнее всего. Если уже есть интересное направление, примерь его обычные задачи и отметь навыки, которые возьмёшь с собой.
4. Сохрани **карту перемен** в PNG. В ней есть сравнение «Сейчас / Хочу», первый шаг, условия по доходу, вопросы о рабочем дне и выбранные навыки. Введённые суммы тоже попадают в файл.

Например, если хочется попробовать выпечку, игра предложит подумать о закупках, работе у печи и расчёте себестоимости. В качестве первого шага можно испечь небольшую партию и собрать отзывы.

В конце есть кнопка «Разобрать результаты со специалистом». Она открывает личный чат в Telegram с черновиком сообщения.

## Как устроен проект

- Весь проект собран в одном файле `index.html`: HTML, CSS, JavaScript и встроенный логотип.
- Ответы и прогресс сохраняются в браузере через `localStorage`. Карта PNG создаётся там же с помощью Canvas.
- Для локального запуска достаточно открыть `index.html` в браузере.
